
# Finance Copilot

AI-Powered Financial Analysis & Decision Support System

Finance Copilot is a desktop application designed to analyze financial transactions, expenses, revenue, and cash flow. It aims to identify unusual spending patterns and provide understandable financial insights through AI.

## Technology Stack

- Java
- JavaFX
- Maven
- SQLite and JDBC
- Python REST API
- LLM API

## Progress

- [x] Project structure

- [ ] SQLite integration
- [ ] Transaction management
- [ ] Financial dashboard
- [ ] Python analysis service
- [ ] AI financial assistant
- [ ] Reports and exports

## How to Run

Requirements: JDK 25 and Maven.

From the desktop-app directory, run:

    mvn clean javafx:run
